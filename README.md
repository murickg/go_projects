# Простой чат-сервер

1.  TCP-сервер, который:
    - Принимает подключения от нескольких клиентов.
    - Пересылает сообщение от одного клиента всем остальным.
    - При подключении нового клиента, оповещает всех об этом.
    - При отключении клиента, также оповещает остальных.
2.  Консольный TCP-клиент для взаимодействия с сервером.
