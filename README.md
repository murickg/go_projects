# Параллельный парсер веб-страниц

Программа для параллельного скачивания и парсинга веб-страниц:
1. Программа принимает список URL
2. Максимум X одновременных запросов
3. Rate limiting: не более Y запросов в секунду
4. Таймаут на каждый запрос: Z секунд
5. Graceful shutdown по Ctrl+C
6. В резульатет выводит Title
  - Формат: CSV
7. Сохранение результатов в файлы
